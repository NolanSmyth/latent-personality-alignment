# EXP-018: Evaluation Methodology Gap — Generation Collapse vs Probability Preservation
*2026-02-25 | Analysis of EXP-002 through EXP-016 results*

## Hypothesis
The apparent safety gains from LPA (ASR→0) and the simultaneous utility collapse (MMLU→0 on eval.py) may be two symptoms of the same phenomenon: **generation collapse**. If the model's generation mode has fallen into attractors (e.g., always outputting "1" or "I do not not"), then:
- Harm evaluations (which examine generated text) will report zero ASR because the model can't produce coherent harmful output
- Generation-based utility evals (eval.py's `MMLUTask`) will report ~0 because the model outputs "1" instead of "A"/"B"/"C"/"D"
- But probability-based utility evals (lm-eval's MMLU) will still score well because they compare $\text{argmax}\big(P(A|\text{context}),\, P(B|\text{context}),\, P(C|\text{context}),\, P(D|\text{context})\big)$ — and the knowledge encoded in the relative probability ordering is preserved

## Evidence

### Two different MMLU evaluation methods

**eval.py** (`tasks/general_capabilities/multiple_choice_tasks.py`):
- Uses `model.generate()` with `max_new_tokens=1`
- Checks if the correct answer letter (A/B/C/D) appears in the generated token
- **This is generation-based** — if the model's top-1 token is "1" or anything other than a letter, accuracy = 0
- Does NOT apply a chat template (raw text prompt)

**lm-eval** (`python -m lm_eval`):
- Computes log-likelihood of each option token given the context
- Selects the option with the highest conditional probability
- **This is probability-based** — even if "1" has higher raw probability than any letter, the correct letter can still have the highest probability *among the 4 options*
- Applies a chat template

### Observed pattern across experiments

| Experiment | Step | eval.py MMLU | Harm ASR | Generation behaviour |
|---|---|---|---|---|
| EXP-002 (200 steps) | 200 | 0.04 | 0.00 | "I do not agree" to everything |
| EXP-010 (100 steps) | 100 | 0.40→0.00 | 0.00 | Collapse after step 50 |
| EXP-015 toward-only | 100 | 0.00 | 0.00 | Generation collapsed |
| EXP-015 balanced | 100 | 0.07 | 0.00 | Generation collapsed |
| EXP-016 Run 2 | 40 | 0.51 | 0.00 | ★ Partial collapse |
| EXP-015 away-only | 100 | 0.71 | 0.47 | Generation intact, no safety |

The pattern is perfectly consistent: **configurations that achieve low ASR also collapse generation (and eval.py MMLU). Configurations that preserve generation (away-only) show no safety improvement.** The away-only condition is the control — it doesn't affect generation and correspondingly shows no safety change.

### What this means for the paper's reported results

The paper reports LPA utility via lm-eval (MMLU 0.71/0.72) — nearly identical to baseline. This is consistent with the probability-preservation hypothesis: the model's internal knowledge representations are intact, so probability-based benchmarks are unaffected. But the generation mode has collapsed, which is what actually produces the "safety" effect.

## Conclusion

**LPA's safety gains are primarily a generation collapse artifact, not genuine personality internalization.** The model is not becoming "more conscientious" — LAT has pushed the generation distribution into low-entropy attractors (repeating training targets like "I agree" / "I do not agree" or degenerate tokens like "1"). This creates a thin wrapper:

1. **Internal representations**: Knowledge and reasoning are largely intact (probability comparisons preserve relative ordering)
2. **Generation surface**: Collapsed — the model outputs training-target text or degenerate tokens instead of following the prompt
3. **Safety evaluations**: Fooled because they evaluate generated text, which is now incapable of producing coherent harmful content
4. **Utility evaluations**: 
   - lm-eval (probability-based): unaffected → "utility preserved" ✓
   - eval.py (generation-based): collapsed → "utility destroyed" ✗

### Implication for next steps
The separate-dataloader approach (TODOS 8a–8d) and loss configuration tuning are optimizing within a paradigm that may be fundamentally limited. To achieve genuine personality alignment (rather than generation collapse), the training must:
- Preserve the model's generation capability while shifting personality
- Use evaluation methods that test *both* probability distributions AND generated text quality
- Consider whether the adversarial training objective inherently pushes toward degenerate generation modes
